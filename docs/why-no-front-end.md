# Why there is no front end

The operating work is a morning evidence review, a restore exercise record and follow-up decisions. A database and command recipes handle that work directly. Read-only HTML gives the team a report to inspect or print in its own brand.

A hosted screen gives shared access, live status, mobile use and direct editing. This base provides none of those. It also has no offline synchronisation, drag and drop, live collection or alert delivery. The local database is available offline to one operator; that is not a shared mobile application.

Enterprise DNA builds the connections and shared views the business needs in its own version. Keep existing backup and notification controls running until those replacements have been verified. The free evidence review works from stored exports without any vendor connection.
